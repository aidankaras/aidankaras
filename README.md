# Aidan Karas

Data Science + Mathematics at Boston University (May 2028). ML research in the Barnes Group; previously Research Software Engineer (DOE SULI) at Argonne National Laboratory.

I build evaluations and tools for LLM systems, and I publish negative results.

- **[model-lab](https://github.com/aidankaras/model-lab)**: LoRA-fine-tuned Qwen2.5-0.5B for email triage (70% vs 53% for rules, McNemar p = 0.003), then showed a TF-IDF baseline ties it at ~90x lower latency.
- **[mcp-risk-census](https://github.com/aidankaras/mcp-risk-census)**: static scan of 109 public MCP servers for shell, file, and network capabilities, with a labeled validation sample.
- **[signal-lab-public](https://github.com/aidankaras/signal-lab-public)**: ~20 pre-registered trading-strategy experiments against SPY and a random-entry control; every concluded one loses out of sample.
- **[agent-readiness-scanner](https://github.com/aidankaras/agent-readiness-scanner)**: checks whether a website is usable by AI agents.
